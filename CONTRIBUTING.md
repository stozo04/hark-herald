# Contributing

Small, focused pull requests are welcome. Open an issue for bugs or bigger ideas. Using an AI agent? Point it at [AGENTS.md](AGENTS.md) first.

Target `main`. Every change needs review by Steven (`@stozo04`).

## Checks

```sh
npm test
npm run build
```

For UI changes, check the page at 390px, about 900px and 1440px wide with no horizontal scrolling.

## Data

Every feature and user count needs its own X post URL. Only what Brett or the Hark team present as a new feature counts toward the twelve; bug fixes and small tweaks don't. Never include credentials or personal data.
